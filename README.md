# 高一学习助手

面向广东佛山高一（理科方向：语数英 + 物化生）的章节学习与笔记程序。
提供 **桌面版**（Python + wxPython）和 **网页版**（手机/平板/电脑浏览器通用）两种使用方式，依据人教版新教材（广东高考 3+1+2 模式）整理。

## 网页版（手机即可访问）

仓库根目录的 `index.html` 是自包含网页版，包含全部 6 科 75 章内容，手机浏览器直接打开即可使用。
部署到 GitHub Pages 后，任何设备访问网址即可学习，无需安装。

**在线访问**：部署后将显示为 `https://<用户名>.github.io/<仓库名>/`

## 功能特点

- **章节导航**：左侧目录树按「科目 → 册 → 章节」组织，一目了然。
- **四标签页**：每个章节包含「知识点 / 考点精析 / 典型例题 / 我的笔记」四个标签。
- **随堂笔记**：像在书本上做笔记一样，为每个章节新建、编辑、删除多条笔记，自动保存。
- **跨科搜索**：顶部搜索框可同时检索六科的知识点与考点，快速定位。
- **学习进度**：标记已学章节，绿色加粗显示，进度统计实时更新。
- **笔记导入导出**：方便备份与迁移。
- **字体缩放**：Ctrl+= 放大、Ctrl+- 缩小，适配不同视力。

## 运行方法

### 方式一：双击启动（推荐）
双击 `run.bat` 即可启动程序。

### 方式二：命令行启动
```bash
python main.py
```

## 环境要求

- Python 3.8 及以上
- wxPython 4.x

安装 wxPython：
```bash
pip install wxPython
```

## 使用提示

1. 在左侧目录树中点击章节，右侧自动显示该章知识点。
2. 切换标签页查看考点、例题，或进入「我的笔记」记录心得。
3. 顶部搜索框输入关键词后回车，可在所有章节中检索并跳转。
4. 读完一章点击「标记已学习」，目录树中该章变绿，进度自动累计。
5. 笔记会自动保存到 `data/notes.json`，可通过「文件 → 导出笔记」备份。
